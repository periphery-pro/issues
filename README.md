# Periphery Issues

The public issue tracker for [Periphery](https://periphery.pro), a tool that finds unused code in Swift projects.

## Before opening an issue

- Read the [documentation](https://periphery.pro/docs), in particular the [troubleshooting guide](https://periphery.pro/docs/troubleshooting).
- Search the [existing issues](https://github.com/periphery-pro/issues/issues) to see if it's already been reported.

## Scope

Issues for all parts of Periphery belong here, including the CLI, the [VS Code extension](https://github.com/periphery-pro/vsx), the [GitHub Action](https://github.com/periphery-pro/actions), and the [Bazel rules](https://github.com/periphery-pro/rules_periphery).
